# 更新日志

## 1.2.3

- 商店跳转用的图鉴改为第一次跳转时才构建（约 250 ms），进商店不再有任何额外卡顿；之后跨波次保留，打开很快

## 1.2.2

- 修复商店卡顿：之前每次进商店都会在 1~2 秒后后台构建两个图鉴（各约 250 ms，正好在刷新、购买时卡一下）
  - 商店跳转用的图鉴跨波次保留，只在进第一个商店的加载帧里构建一次；之后列表内容不变就不重建（买东西不再导致重建）
  - 不用时移出场景树，进商店时的卡顿不再因为图鉴的节点数变长
  - 局内暂停菜单里的图鉴不再后台预先构建（打开时再构建）

## 1.2.1

- 多人：商店里打开图鉴时按操作的玩家显示（攻速、范围、武器数量、进化、噩梦、禁用道具、描述数值）；暂停菜单里的图鉴按菜单当前显示的玩家
- 多人：快捷键 / R3 按各玩家自己的焦点找物品；商品描述的异变预览按卡片所属玩家显示（异变果条件与游戏一致：任一玩家的可异变道具够数即可掉落）

## 1.0.0

- 首个版本：把网页图鉴（brotato.mojimoon.top）的功能搬进游戏内图鉴
- 列表：价格 / 数量上限 / 来源（DLC、机械 / 异变）角标，可开关；搜索，按稀有度、标签、来源、特殊（化石 / 机械 / 异变）、类型、武器类别筛选
- 详情：标签、武器类别、关联道具可点击跳转；诅咒（局内高亮本波可能的强度范围，默认中位数）、机械化、异变（可复制 / 可清除的效果）预览；攻速计算器；价格计算
- 武器属性中的冷却改为实际平均冷却（与 ImprovedTooltips 兼容）
- 局内打开时，异变、攻速、范围、武器数量、波次、难度默认取当前值
- 武器 / 难度选择界面：显示角色的偏好标签、禁用道具与异变预览，点击打开图鉴并筛选
- 商店：右键商品或已有武器 / 道具（或悬停时按 C、手柄 R3）打开图鉴并定位到它，已有的诅咒 / 机械化物品按实际强度预览
