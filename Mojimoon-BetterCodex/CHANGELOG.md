# 更新日志

## 1.1.3

- 适配 1.2.0.2-beta 的机械 / 异变调整：异变上限、缩放公式与可复制条件都直接取游戏自身的计算
- 价格计算改用游戏的 ItemService.get_value（去掉玩家的价格效果），噩梦通胀取自难度数据
- 商店：可掉落异变果时，悬停角色 / 已有道具，在物品弹窗旁显示哪些效果可被复制、清除
- 商店的异变果提示改为买卖道具（材料变化）时刷新

## 1.1.2

- 修复：关联内容中当前道具的图标异常地小
- 机械 / 异变道具的图标也移到右下角；所有来源图标加黑色描边（深海魔怪的蓝色在 T2 道具上也看得清）
- 武器的类型与类别改为与道具标签相同的超链接
- 去掉图鉴边框贴图伸进内容区的涂鸦（左上角、右下角会遮挡内容）
- 图鉴进度按真实存档计算（开启“解锁全部图鉴”时也一样）
- 角色信息栏的禁用道具图标放大，一行 5 个

## 1.1.1

- 修复：游戏启动时仍可能卡死（翻译文件改为整体读入后拆行，与其他 mod 相同）
- 列表来源角标移到右下角，改为物品套组的彩色图标（机械 / 异变道具不变）
- 道具的标签显示在图鉴标题下的类别行（“限制 (X)”“构筑物”之后），点击筛选

## 1.1.0

- 修复：游戏启动时卡死（从 zip 读取翻译文件时死循环）
- 修复：没有可被异变清除的效果时仍显示“异变无法清除”
- “角标”按钮改为“设置”：可分别开关价格 / 数量上限 / 来源角标，修改商店跳转图鉴的快捷键，解锁全部图鉴（不修改存档），快速打开图鉴（跳过动画，默认开启）
- 局内打开图鉴时，P1 被禁用的道具变灰（角色自带禁用 + 消耗禁用次数禁掉的）
- 武器的类型与类别显示在图鉴标题下原来的类别处，可点击筛选
- 价格计算不再重复显示基础价格，难度改为“噩梦”开关，显示第 1、5、10、15、19 波
- 攻速计算器的帧数单位统一为 f；“临时筛选”改为“筛选”
- 角色的偏好标签改为一个筛选，包含带任一偏好标签的道具
- 商店左下角提示快捷键，以及异变果能否掉落（未诅咒道具不足 3 个时显示进度；机械路线不显示）
- 异变的最大值与缩放公式直接取游戏的（兼容之后版本的调整）
- 武器 / 难度选择界面的角色信息栏变窄，难度选择界面不再溢出

## 1.0.0

- 首个版本：把网页图鉴（brotato.mojimoon.top）的功能搬进游戏内图鉴
- 列表：价格 / 数量上限 / 来源（DLC、机械 / 异变）角标，可开关；搜索，按稀有度、标签、来源、特殊（化石 / 机械 / 异变）、类型、武器类别筛选
- 详情：标签、武器类别、关联道具可点击跳转；诅咒（局内高亮本波可能的强度范围，默认中位数）、机械化、异变（可复制 / 可清除的效果）预览；攻速计算器；价格计算
- 武器属性中的冷却改为实际平均冷却（与 ImprovedTooltips 兼容）
- 局内打开时，异变、攻速、范围、武器数量、波次、难度默认取当前值
- 武器 / 难度选择界面：显示角色的偏好标签、禁用道具与异变预览，点击打开图鉴并筛选
- 商店：右键商品或已有武器 / 道具（或悬停时按 C、手柄 R3）打开图鉴并定位到它，已有的诅咒 / 机械化物品按实际强度预览
