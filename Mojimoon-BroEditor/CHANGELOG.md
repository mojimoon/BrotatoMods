# 更新日志

## 0.9.0

- 蓝图页新增导入 / 导出蓝图（分享码前缀 `BEB:`，与顶部的导入导出分开）；清空蓝图需要确认
- 初始武器：新增"从角色导入"，以表格列出每个角色的初始武器，点击即采用
- 初始武器：移除"全部 T1–T4"按钮；武器选择弹窗新增稀有度、近 / 远战、来源筛选，以及"选中当前全部""取消当前全部""重置全部"
- 列表下方新增"全部重置"：先勾选要重置的内容（禁用状态、修改内容、自定义内容），再最终确认；重置自定义内容时编号一并重置
- 重置单个、删除改为弹窗确认
- 弹窗统一为一个类（选择弹窗、确认框等），Esc 关闭最上面的弹窗
- 修复：概览预览中蓝图的效果没有和其他效果一样逐行显示（现在每条路径一行，带属性图标）

## 0.8.4

- 修复：0.7.5 起道具、武器的属性页错误地显示角色的属性页（开局状态 + 全部属性）。现在道具 = 价格 / 数量限制 / 稀有度 + 属性表，武器 = 价格 + 武器属性
- 效果页确认无误：角色和道具共用一个效果库，武器的效果库另含来自武器的效果

## 0.8.3

- 属性页各数值的效果文本改用原版字符串：属性获取修改为"生命再生的修改减少100%"，属性上限为"闪避上限为90%"，次要属性、商店、地图、规则等优先用原版对应效果的文本
- "箱子里的材料"更名为"拾取箱子时获得材料"（同袋子）

## 0.8.2

- 停用某个 mod 后，基于该 mod 内容新建的角色 / 道具 / 武器、对该 mod 内容的修改、来自该 mod 的效果都不再显示，档案保留，重新启用该 mod 后恢复
- 原版角色的初始武器全部来自已停用的 mod 时，保留原版初始武器
- 测试：新增 compat_off 组（卸下 BroLab、Modtools 后检查上述情况）

## 0.8.1

- `custom/` 下按种类分成 `character/`、`item/`、`weapon/` 三个子文件夹，便于只分享其中一类

## 0.8.0

- 新建的角色 / 道具 / 武器各自保存为独立的单行 JSON（`custom/<id>.json`），复制给别人即可分享；profiles.json 只保存对原版的修改与设置（旧存档中的自定义对象在下次保存时自动迁移）
- 新增 README（中英文，Markdown + BBCode），说明功能与配置文件位置

## 0.7.5

- 调整部分页签的颜色和顺序

## 0.7.4

## 0.7.3

- 三栏的概览页改用同一套组件（基础信息、外观、词条 / 类别、预览）

- 显示键名时，角色 / 道具词条和武器类别按钮里另起一行显示键名

- 分享码前缀更新（BE0: / BEC: / BEI: / BEW: / BEA:）

## 0.7.1

- 恢复删除 / 改名自定义角色时的检查：存档中进行中的一局正在使用该角色时拒绝（否则读档后那一局无法继续）；检查只看各玩家的当前角色，不会再导致崩溃
- 角色的“初始属性”页更名为“属性”
- 武器属性“命中减速”更名为“%命中敌人速度”，正负号与原版一致（负数 = 减速）
- 测试按组拆分（core / ui / battle），新增与 BroLab、Modtools 同时加载的兼容性测试（compat）

## 0.7.0

- 新建的角色 / 道具 / 武器可自行输入 ID 后缀（字母、数字、_，空格自动转为 _），默认为 <基底>_<随机数>，导入时不易重复
- 新建自定义武器时复制基底的全部等级；不再支持切换近战 / 远战
- 右上角新增“隐藏编号”：隐藏使用原版图标的自定义对象右下角的编号
- 武器属性页重新排布；新增横扫 / 突刺（仅近战）与近战 / 远战（只读）；“命中减速”按正数填写；移除无实际作用的“治疗武器”
- 攻击间隔改为“实际冷却”，左右两侧一致
- 道具与武器的效果预览显示价格；武器家族预览改为分块显示，当前等级以底色突出，点击可切换等级
- 琉特琴、粒子加速器、十字弓的武器效果归入战斗类
- 移除“存档中正在使用”的删除检查（该检查在有存档时会导致游戏崩溃）；删除进行中一局用到的道具 / 武器后读档，它们会被跳过
- 中文“扳机”改为“触发”；“远战武器”用语修正；同步各语言的说明文字

## 0.6.0

- 角色栏也可按来源筛选；来源统一为 原版 / DLC1 / 模组，本模组新增的角色、道具、武器都属于模组
- 每个对象右上角新增“禁用”开关：禁用的角色不可选，禁用的道具 / 武器不会出现在商店、箱子与初始武器中（武器按家族禁用全部等级），左侧列表中变灰；受本栏总开关控制
- 道具、武器的概览页与属性页分开（概览：名称、外观、标签 / 类别、预览；属性：价格、稀有度、数量限制、属性表 / 武器属性）
- 新建自定义道具：同角色，以基底道具决定外观，图标可选或导入
- 武器：左栏每个家族只显示最低等级，右上角切换等级；预览同时显示整个家族
- 武器属性改用内部参数（冷却、后坐、后坐时长、换弹发数 / 倍率），并按原版规则显示估算的攻击间隔（同 AutoAnthony）
- 新建自定义武器：以基底武器决定外观与近 / 远战（可切换），逐级补到 T4；未补齐前自动禁用但仍可编辑
- 武器类别对全部等级生效；原版武器可补更低等级的版本（自动接入升级链）
- 批量导出带上武器家族与禁用列表

## 0.5.0

- 升级为多功能编辑器：同 AutoAnthony 的三栏页签（角色 / 道具 / 武器），每栏右侧的总开关可一键启用 / 停用该栏的全部修改
- 道具、武器：左栏支持搜索，按来源（原版 / DLC / 模组）、稀有度、标签（武器为类别）筛选，按稀有度 / 名称 / 价格排序
- 道具、武器均有属性、效果、蓝图页；道具属性页可改名称、价格、稀有度、数量限制、标签与属性表，修改稀有度后会重建商店池
- 新的武器属性页：伤害、冷却（秒）、暴击、命中、范围、击退、生命窃取、投射物 / 贯通 / 反弹等原版字段，以及属性加成；右侧预览与原版武器面板一致
- 武器的效果库额外包含原版武器自带的效果
- 导出改为下拉菜单：导出当前项目（BE1:）、导出全部角色 / 道具 / 武器（BEC1: / BEI1: / BEW1:）、导出全部（BEA1:）；导入时自动识别
- 编辑效果时只显示主键名；调试模式下各处显示主键名与其他键名，不再显示来源文件
- 标题改为 “BroEditor”
