# 更新日志

## 0.5.0

- 升级为多功能编辑器：同 AutoAnthony 的三栏页签（角色 / 道具 / 武器），每栏右侧的总开关可一键启用 / 停用该栏的全部修改
- 道具、武器：左栏支持搜索，按来源（原版 / DLC / 模组）、稀有度、标签（武器为类别）筛选，按稀有度 / 名称 / 价格排序
- 道具、武器均有属性、效果、蓝图页；道具属性页可改名称、价格、稀有度、数量限制、标签与属性表，修改稀有度后会重建商店池
- 新的武器属性页：伤害、冷却（秒）、暴击、命中、范围、击退、生命窃取、投射物 / 贯通 / 反弹等原版字段，以及属性加成；右侧预览与原版武器面板一致
- 武器的效果库额外包含原版武器自带的效果
- 导出改为下拉菜单：导出当前项目（BE1:）、导出全部角色 / 道具 / 武器（BEC1: / BEI1: / BEW1:）、导出全部（BEA1:）；导入时自动识别
- 编辑效果时只显示主键名；调试模式下各处显示主键名与其他键名，不再显示来源文件
- 标题改为 “BroEditor”

## 0.4.2

- 效果页：初始属性的每一项、每件额外初始装备、蓝图各占一行，可以单独调整顺序；调整顺序改为拖动（按住一行拖到目标位置，落在目标行的上半 / 下半即插在前 / 后）
- 效果页：点“编辑”展开后显示灰色键名
- 新增调试模式（标题栏开关）：效果列表、效果库、初始属性旁显示灰色键名
- 修复蓝图节点的标题显示在节点框外
- 概览页的初始武器改为方形图标格

## 0.4.1

- 入口按钮在所有语言下都显示为 “BroEditor”
- 概览页效果预览改用原版角色面板的排版（左侧图标、右侧文本），可选初始武器显示为图标
- 效果页：初始属性、额外初始装备、蓝图生成的效果也显示在列表中（只读，标明来源），可调整它们在效果列表中的顺序
- 效果页：“是 / 否”字段改为紧凑的切换按钮，不再撑高整行；效果库分类按钮不再把右栏撑出屏幕
- 初始属性页：“移动时可攻击”改为直接设定（默认显示角色自身的值：一般为 1，士兵为 0；改为 1 可让士兵移动时攻击）
- 初始属性页：修正“%升级需要经验值”的名称；“折磨”改为与道具同名的“拷问”
- 禁用页按稀有度排序
- 蓝图页说明：多个条件可以串联，条件可以分叉连接多个扳机或效果

## 0.4.0

- 支持游戏的全部 13 种语言（English、Français、中文、日本語、한국어、繁體中文、Русский、Polski、Español、Português、Deutsch、Türkçe、Italiano）
  - 属性名直接使用原版各语言的标签；蓝图效果的扳机 / 效果句式与东尼算法一致，语序随语言变化（中文“扳机在前”，英文等“效果在前”）
  - 缺少翻译时：中文系回退到中文，其他语言回退到英文

## 0.3.2

- 中文用语对照原版：贯通、反弹、构筑物、头目、战利品外星人、敌袭、%X修改（属性修改）等；属性名优先使用原版标签
- 蓝图效果文本改为原版 / 东尼算法句式：“扳机 + 效果”，几率与“每 N 次”并入句子，每波上限与其他条件以括号接在后面（例：每杀死5个敌人，+1护甲，直至敌袭结束（每波最多3次））

## 0.3.1

- 修复：编辑器里输入 W / S 等字母仍会在输入框之间跳转（打开编辑器期间暂时解除字母键的界面导航绑定，关闭后恢复）
- 修复：下拉列表滚动到底部后继续滚动会关闭列表
- 初始属性：属性上限移到基础属性列下方；“商店与材料”和“地图与敌人”分为两组
- 次要属性图标改为对应的原版道具图标（尖头子弹、跳弹、优惠券、望远镜、危险的兔子、吞吞怪之帽、幼年异形、外星绅士、回收装置、猪猪存钱罐、悲伤的番茄、奇怪的幽灵等）

## 0.3.0

- 蓝图与效果编辑：扳机 / 条件 / 效果、属性等下拉框改为可搜索的列表（左边名称，右边灰色键名；回车选第一项）
- 效果库分类：构筑物与宠物分开，新增“属性修改”，经济 / 商店不再混入伤害、回血等效果
- 自定义角色：使用原版贴图时图标右下角标上编号；可导入自己的图片（png / jpg / webp）作为图标
- 修复：编辑器里输入 W / A / S / D 等字母会跳到其他控件；松开 Esc 关闭编辑器时会让选择界面返回上一页
- 初始属性改为三列，基础属性、属性获取修改、次要属性同一行对齐，属性名左边显示图标
- 兼容其他 mod：可选择 mod 的武器 / 道具 / 角色；mod 的效果文本按原版默认规则显示
- 可选初始武器：新增“全部 T1–T4”按钮（再次点击全部移除）
- 右上角“重置”按钮常驻，没有修改时置灰

## 0.2.0

- 新增“蓝图”页：节点图编辑器，自由连接扳机 → 条件 → 效果（24 种扳机、12 种条件、14 种效果，含“获得效果库中的任意效果”），不限制组合
- 效果页的原版触发型效果（升级时、静止时、每波结束时……）可一键“拆解”为蓝图路径
- 初始属性页：新增开局状态（初始材料、初始等级 / 结算升级、开局箱子 / 传奇箱子、额外禁用次数、起始波次、波次时长），属性获取修改 %，属性上限，以及更多次要 / 世界属性
- 移除全部悬浮提示；移除效果页的单行蓝图（由蓝图页取代）
- 修复：选择界面与战斗场景的原版初始化被执行两次

## 0.1.0

- 首个版本：角色编辑器（角色 / 武器 / 难度选择界面左上角进入）
  - 修改任意原版角色：名称、介绍、效果（增删改、排序）、初始属性、可选初始武器、额外初始道具 / 武器（可诅咒）、偏好词条、禁用道具 / 武器系列；可随时停用或重置
  - 新建自定义角色：以任意角色为基底（外观、效果、初始武器），可换图标，在选角界面直接选择
  - 效果蓝图：扳机（升级时、每波结束时、静止时、生命低于一半时……）+ 属性 + 数值
  - 效果库：全部原版角色与道具的效果，按类别筛选、搜索，添加后可修改任意数值字段
  - 分享码导入 / 导出
