# 更新日志

## 1.8.9

- 武器概览页“武器类别”与“分组”之间新增“初始武器”：选择可以该武器为初始武器的角色（修改的是角色的初始武器）。
  - “选择角色”可按来源筛选、批量选中 / 取消；“套用已有武器”采用另一件武器的使用者。
  - 新加入的角色使用该武器的最低等级，并遵守角色的“最低 / 最高武器等级”效果（如骑士）。
- 导入不完全或 mod 未启用时更稳健：提及未知的道具、武器、效果、标签、类别、分组成员时不生效、不改动档案、不报错，补上相应内容后正常生效。
  - 修复：蓝图中不认识的节点（来自更新的版本）会让编辑器报错；不认识的条件会被当作满足。
  - 修复：“移除后变成”指向未知道具时会清掉原版的设置。
  - 修复：基底缺失的自定义武器类别仍会注册（持有 2 件时出错）。
  - 自定义图标文件缺失时直接使用基底图标，不再输出错误。

## 1.8.8

- 蓝图新增条件“拥有指定道具/武器”：拥有至少 / 至多 / 恰好 N 件某道具，或某武器（任意等级）。
- 角色 / 道具的标签与武器类别、分组一致：标题行右侧“管理”，自定义标签在管理窗口中新增。
- 修复：自定义武器改名后，左侧预览显示基底武器；自定义道具改名后，左侧预览显示无效果（需重新打开编辑器才恢复）。

## 1.8.7

加入 BroEditor+（BEP-BroEditorPlus）的部分特性：

- 蓝图新增条件：
  - “拥有标签道具”：拥有至少 / 至多 / 恰好 N 件带某标签的道具。
  - “拥有类别武器”：拥有至少 / 至多 / 恰好 N 把某类别的武器。
  - 两者都是状态条件，接在“始终”等状态扳机上时，条件不再满足会自动撤销。
- 蓝图新增效果：
  - “商店必定出现”：下次刷新的商店包含所选道具 / 武器（随一局存档保存）。
  - “解锁分组 / 锁定分组”：永久改变分组的锁定状态，可做“满足条件后解锁”的内容。
- 内容分组：概览页新增“分组”，可把角色 / 道具 / 武器加入分组；“管理”中可新建、重命名、删除分组，或整组锁定 / 解锁。
  - 锁定使用原版的解锁记录（写入游戏存档）：锁定的角色不能选择，道具和武器不会出现在商店中；解锁或删除分组后恢复。
