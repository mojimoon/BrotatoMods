# 土豆兄弟：东尼算法（Brotato: Auto-Anthonyology）

> 灵感来自《杀戮尖塔 2》的东尼算法 mod（AutoAnthony）：每局开始时，把原版内容拆成可复用的组件，再按价值预算重新组装。

## 功能

在**角色选择 / 武器选择 / 难度选择界面左上角**（返回按钮旁）点击 **东尼算法** 打开设置。设置在选定难度、进入战斗时生效。

设置页上方分三张卡片：**重组内容**（道具 / 角色 / 武器 / 名称）、**效果设置**（更多角色效果 / 全部角色效果 / 更多双面效果）、**数值设置**（四个滑条与种子），每个选项下方用灰色小字写明实际效果。下方是**道具预览**：按当前设置与种子生成整张道具池（不影响游戏），按稀有度分页，每件道具一张卡片（图标、名称、价格、独特标记、带颜色的效果）。

## 设计思路

### 1. 从《杀戮尖塔 2》东尼算法学到什么

AutoAnthony 的核心是三件事：

1. **拆解**：把每张原版卡拆成带结构化运行规格的 unit operation（伤害、格挡、抽牌……），触发器（“每回合开始时”“每打出一张攻击牌时”）本身也是一种组件，与载荷之间用“触发者索引”相连。
2. **价值货币**：1 点价值 ≈ 1 点单体伤害；每种效果有换算价格；**触发器按“每回合期望触发次数”折算**，频率越高单次载荷越小（每打出一张牌 25%、回合开始 52%、低概率条件 155%……）。
3. **频率先验**：组件出现概率不靠手写表，而是从原版卡池统计（经验贝叶斯平滑），保证原版组合都能重现、未出现过的组合也有非零概率；整卡再用一个统一预算包络校准。

### 2. Brotato 的问题：效果易估价，扳机难组合

Brotato 的道具效果大多是**一条一条独立的属性加减**，而且每件道具都有明码标价。对原版纯属性道具做岭回归（`价格 ≈ 稀有度截距 + Σ 属性权重 × 数值`），平均误差只有约 10%，所以“效果的价值”很好处理。

四种基础伤害属性再用升级选项校准（同档升级的价值相同：T1–T4 远程 / 元素 +1/2/3/4、工程 +2/3/4/5、近战 +2/4/6/8），得到 远程 5.0 > 元素 4.4 > 工程学 3.3 > 近战 2.8；回归值中工程学（2.1）明显偏低、近战（3.4）偏高，已按升级比例修正。升级里的生命再生、吸血、范围性价比偏低，不用于校准。

真正的设计难点在**触发扳机**。统计原版 592 条道具效果：约 70% 是纯属性行，而触发型效果有 25 种左右，**每一种都是写死的“特定扳机 + 特定载荷”专用 key**：

| 原版 key | 扳机 | 载荷 | 数据格式 |
| --- | --- | --- | --- |
| `stats_on_level_up` | 升级 | 永久属性 | `[stat, value]` |
| `temp_stats_on_hit` | 受击 | 临时属性 | `[stat, value]` |
| `heal_on_dodge` | 闪避 | 回血 | `[?, value, chance]` |
| `dmg_when_death` | 敌人死亡 | 按属性造成伤害 | `[stat, pct, chance, tracking]` |
| `explode_on_hit` | 受击 | 爆炸 | `ItemExplodingEffect` 对象 |
| `stats_end_of_wave` | 波末 | 永久属性 | `[stat, value]` |
| … | … | … | … |

每个 key 在 `main.gd` / `player.gd` / `unit.gd` 里各有一段专门的读取代码。想要“闪避时获得材料”或“击杀时爆炸……每 N 次”，原版根本没有对应的 key。**扳机和载荷是焊死在一起的**，这就是无法自由组合的原因。

### 3. 解决方案：通用触发条款 = 扳机 × 载荷 × 门控

本 mod 新增一个通用效果类 `aa/trigger_effect.gd`（`get_id() = "aa_trigger"`），一条效果就是一个条款：

```
trigger  扳机   kill / hit / dodge / consumable / gold / heal / level_up / wave_start / wave_end / interval
               still / moving / low_hp / full_hp（状态）/ reroll / buy（商店）
payload  载荷   temp_stat / perm_stat / timed_stat / heal / gold / xp / damage / explode
门控           param（每 N 次 / 间隔秒数）、chance（几率）、cap（每波上限）
```

它**不写入玩家的 effects 字典**（那里每个 key 的数据格式都不同），而是由一个运行时触发总线 `aa/runtime.gd` 统一派发：

- 原版事件通过脚本扩展和信号转发进来：`main._on_enemy_died`（击杀）、玩家的 `took_damage` 信号（受击 / 闪避）、`on_consumable_picked_up`、`on_gold_picked_up`、`on_levelled_up`、`on_player_healed`、波次开始（`players_spawned`）与结束（`_on_WaveTimer_timeout`）、商店的刷新与购买。
- 总线扫描玩家角色、道具、武器上的条款，处理门控（每 N 次计数、几率、每波上限），然后执行载荷。载荷的实现全部复用原版 API：`TempStats`、`RunData.add_stat / add_gold / add_xp`、`healing_effect` 信号、`take_damage`、`WeaponService.explode`。
- 状态扳机（静止 / 移动 / 低血 / 满血）每 0.2 秒轮询，进入时加临时属性、离开时移除。
- 限时属性用带“波次序号”的计时器移除，防止波末 `TempStats` 整体重置后再被错误扣减；深度限制防止“回血 → 伤害 → 击杀 → 回血”之类的连锁递归。

于是**任何扳机都能驱动任何合法载荷**。合法性由一张表决定（`catalog.LEGAL`），只排除没有意义或会自激的组合：状态扳机只挂临时属性；商店扳机只挂永久属性 / 材料；回血扳机不挂回血、拾取材料不挂材料；波初 / 波末不挂伤害类载荷。原版的 29 种触发效果全部能被这套通用系统重新表达（测试 `test_15` 验证），合法组合共 67 种，生成中实际出现 60 种以上。

### 3.1 自由触发：任何效果都能成为触发的结果（默认规则）

东尼算法（STS2）构筑性高的一个原因，是"能力牌"的触发器后面可以挂几乎任何效果。除了上面 8 种载荷，还有一种 **"获得效果"**：触发时获得一条完整的效果，候选来自

- 可缩放机制（穿透、弹射、双倍材料几率、Boss 伤害、燃烧扩散、材料掉落……），
- 计数型（"每有 N 个 [计数] +X [属性]"），
- 属性修改（"[属性] 修改提高 X%"）。

例如"每杀死8个敌人，获得「穿透 +1」，直至敌袭结束"、"当站立不动时，获得「护甲修改提高 50%」"、"敌袭结束时，永久获得「近战伤害修改提高 5%」"。

两种模式：

| 模式 | 行为 | 允许的效果 | 估值 |
| --- | --- | --- | --- |
| 本波获得 | 每次触发叠加一份，波末撤销（死亡 / 退出 / 重开时也撤销） | 战斗中实时读取的机制（`GRANT_TEMP_KEYS`）、计数型、属性修改 | 单位价值 × 数量 × 平均叠层（状态扳机为在场率） |
| 永久获得 | 永久写入属性，高频扳机加每波上限 | 所有求和型数值效果（存档安全） | 单位价值 × 数量 × 每波次数 × 累积倍率 |

特判：

- 商店扳机（刷新 / 购买）与波末只能"永久获得"；道具价格、刷新价、回收收益、收获增长、存钱罐这类战斗外生效的效果只能永久获得；
- 镜子（复制）、金鱼（升档）、沙漏（倒流）、珍珠（额外掉落）绑定或消耗持有者，**不能**作为触发结果；下波低血开局、每秒掉血、受击保护、宠物数量、敌人数量等生效时机特殊，也不能；
- 建筑、宠物、受击爆炸等对象型机制在波中途加入可能在刷新前被访问，不作为触发结果。

合法组合同时放宽（`catalog.FREE_LEGAL`，共 93 种），只排除自激循环（回血→回血、拾取材料→材料、升级→经验）和无意义组合（波初造成伤害、波末回血等）。（经典合法表为 67 种，仅供测试对照。）

### 3.2 下一波与同扳机正负成对

- **下一波**（原版芹菜茶、孔雀、围巾）：一次性效果，写入原版的"下一波"清单，下一波开始时生效一次后清空。一波的价值 = 整局持有价值 / 剩余波数（剩余波数 ≈ 2 × 永久累积倍率 − 1）；用孔雀校准，估值 23.6 与预算 23.6 吻合。正面偏向经验 / 收获 / 幸运（原版只用于经验），约一半附带同一行为下的负面行（50% 敌人生命 / 伤害 / 速度提高，50% 自身属性降低）；"下一波：敌人 +X%"也可单独作为代价（出现概率已略微降低）。敌人速度按孔雀校准：+25% 敌人速度 ≈ +50% 敌人伤害，即每 1% 速度按伤害的 2 倍估值（权重 1.6 / 0.8）。敌人生命 / 伤害 / 速度也会作为负面触发条款的结果单独出现（负面临时 / 限时属性条款 30% 使用敌人属性），以及成对条款的负面半边、船长式"每波结束时敌人属性提高"。
- **临时最大生命**：原版降低最大生命时不压低当前生命、升高时把差值加到当前生命。本 mod 的状态 / 限时 / 本波效果降低最大生命时（开启、结束或"受伤时清空"），当前生命 = min(当前生命, 降低后的最大生命)，否则满血时"移动时 -2 最大生命"每走停一次生命就超出上限 2 点并不断累积。未满血时走停仍会按原版规则补回升高的差值。
- **暴击击杀**：原版的死亡是延迟调用，发出受伤信号时敌人尚未标记死亡，按"本次伤害后生命为 0"判断。
- **同扳机正负成对**：属性类触发条款有 40% 概率紧跟一条同扳机、同门控、同载荷方式的负面条款（敌人属性提高，或自身其他属性降低），例如"当移动时，+9%速度""当移动时，-16%攻击速度"。两条是**独立的效果**，负面条款按负面除数折价，省下的预算补给道具其他部分；敌人属性条款使用原版的"负面"符号，估值为负。

### 3.3 更多扳机、词条绑定与角色效果

- **新扳机**：暴击击杀（触手、狩猎奖杯）、击杀燃烧中的敌人（鬼火）、每走 N 步（徒步旅行者，计步方式与原版一致：移动时长 × 2 / 移动动画时长，不依赖 DLC）、波次进行到一半时（赛博格）。原版对应效果不再近似成"击杀"。
- **触发条款的文本**：句式与措辞按原版同类效果（13 种语言逐条对照原版译文），分隔符预先写在各语言的触发文本里。中日韩、繁中、土耳其语"触发在前"：简体中文短条件直接接效果（"移动时+5%速度""杀死敌人时有25%概率恢复2点生命值"），长条件（计数、带属性名或百分比的命中条件）自带"，"（"每杀死4个敌人，+1最大生命值""命中生命值高于75%的敌人时，有65%概率+1近战伤害，持续4秒"）；英、法、德、西、葡、意、波、俄"效果在前"（"+1 Max HP for every 4 enemies you kill"）。本波属性写"，直至敌袭结束"，限时写"，持续X秒"，永久属性不加修饰（同原版"敌袭结束后+3近战伤害"）；"获得效果"不再包一层"获得「」"，直接写效果原文（"移动时%速度的修改增加50%"），效果在前的语言改为"触发：效果（持续时间）"；属性类条款的每波上限写成原版的"每波最大值：+N"（总量），其余写次数。
- **剩余原版触发型效果的拆解**：婴儿胡子 / 外星之眼（新载荷"发射 X 个投射物，每个造成相当于 Y% [属性] 的伤害"，有位置时从该处向四周发射，否则环绕玩家）、害怕的香肠（新载荷"点燃该敌人，3 跳 × X（+100% 元素伤害）"）、丑牙（新载荷"降低该敌人 X% 速度，最多 4X%"）、果篮（新载荷"掉落 X 个水果"）；点燃 / 减速只挂有目标敌人的扳机。新扳机"砍倒树木时"（每波约 3 棵）、"每次获得一个提升 [属性] 的道具时"（雪球，商店阶段，条件属性即效果属性，只挂永久属性）。"击杀被诅咒的敌人时"按击杀的 1/4（每波约 25 次）估值，带这个扳机的道具附带原版黑旗式的 +5 诅咒。商店扳机现在也能执行"随机主属性"（此前在商店里不生效）。
- **更多原版触发型效果的拆解**：冰块（首次被元素伤害命中时 → 受伤加成）、金属探测器（拾取材料时几率 → 材料；拾取材料扳机因此允许挂材料载荷，直接加到材料数，不生成掉落物，不会循环）、巨型带 / 希腊火（暴击 / 燃烧时 → 新载荷"按敌人当前生命值的 X% 造成伤害"，头目和精英为 X/10%，单次最多 10%，只挂有目标敌人的扳机）、糖果袋（每波结束时 → 新载荷"将 X 点属性点随机分配到主要属性上"，按永久效果处理）、黑旗（新扳机"击杀被诅咒的敌人时"，按每波约 5 个估值）。这些原版行不再整条搬运，只作为组合先验。
- **易伤与增伤**：易伤挂在敌人身上，联机时所有玩家的命中（含燃烧）都享受；增伤只对来源玩家生效。原版所有易伤与条件增伤（小鱼、三叉戟、镰刀、厨师、水手）在同一个加成池里相加后整体乘一次；%伤害、对头目和精英伤害、暴击伤害是独立倍率。本 mod 的"使该敌人受到的伤害提高"按原版受伤加成的规则叠加：每条条款是一个来源，同一来源不叠层（取较大数值、刷新持续时间），不同来源相加；同 ID 的多件道具共用来源。搬运到其他道具上的冰块效果以持有者为来源（不同道具可相加）；潜水员"远程命中 +300% 易伤"不搬运（角色另有大幅提高敌人生命作补正）。
- **词条绑定**（`catalog.TAG_BINDINGS`）：暴击击杀 → 暴击；击杀燃烧敌人、"每个燃烧敌人"、燃烧类机制 → 元素；"每个建筑"、建筑类机制 → 构筑物；静止 → 静止；每走 N 步 → 速度；材料 / 和平主义者 → 经济。依据原版同类道具的词条，并补上原版漏标的"每个燃烧敌人""每个建筑"。补充：闪避时（肾上腺素、还击）→ 闪避；拾取材料时（可爱猴子、小象）→ 拾取；拾取箱子（袋子）→ 探索；首次用 [类型] 伤害命中 → 该伤害属性；点燃 / 暴击 → 元素 / 暴击；爆炸载荷 → 爆炸；伤害 / 爆炸载荷的缩放属性（赛博球按幸运造成伤害 → 幸运）；受伤加成 / 对首领增伤 / 对高血量目标增伤 → %伤害；计数型的计数属性（每点护甲 +生命 → 护甲）；敌人减速 → less_enemy_speed；诅咒敌人掉材料 → 诅咒；材料 / 拾取 / 经济 / 探索 / 消耗品类机制按原版来源道具。带 custom_key 的属性型机制（改良工具的构筑物攻速）按来源道具的词条，不再误标成普通属性。测试 `test_114` 逐条检查生成效果都带上绑定的词条。
- **角色效果（默认进入道具池）**：使用 [类型] 武器 +X [属性]（狂人、医生、斗士……，价值 = 属性权重 × X × 0.35 的类型占比）、+1 武器栏（道具上为累加；武器栏受规则限定的角色不会刷到）、对燃烧目标额外伤害（厨师）、波末每个存活敌人获得材料与经验（和平主义者）；计数新增"每个空闲武器栏"（船长）与武器数量计数"每把 [不同 / 所有 / IV 级 / I 级] 武器 +X [属性]"（角斗士、多面手、国王；计数期望 3.5 / 5 / 1 / 1.2）；代价新增"每波结束时敌人属性提高"（船长），−1 武器栏移入"更多双面效果"选项。
- **下一波**的正面只生成 +经验（70%）或"下一波额外出现战利品外星人"（30%，原版诱饵，每个约 4.6）。下一波经验每 1% 很便宜（约 0.08），预算常远超上限（原版单行最大 +50% × 1.25 × 2 = 126%）；超出时不再一律取上限，而是在上限的 40%–100% 之间随机（5 的倍数），剩余预算留给道具的其他行，成对的代价按比例缩小。
- "获得效果"载荷权重提高到 2.5。

### 3.4 实验性扳机与连锁触发

东尼算法（STS2）的一大特点是"A：触发 B""B：触发 C"可以连锁。这里加入一组低权重的实验性扳机（约占触发条款的 7%），它们的来源大多是原版道具里还没被拆开的触发条件，并且能被其他条款的载荷再次触发：

| 扳机 | 来源 / 钩子 | 每波次数估计 | 可被哪些载荷连锁触发 |
| --- | --- | --- | --- |
| 拾取箱子时 | 原版袋子（"拾取箱子时获得材料"现在拆为 拾取箱子 → 材料）；拾取消耗品钩子 | 1.2 | — |
| 引发爆炸时 | 原版 `WeaponService.explode`（任何来源的玩家爆炸） | 8 | 爆炸载荷 |
| 暴击时 | 原版敌人受伤信号的暴击标记 | 80 | 伤害 / 爆炸载荷暴击 |
| 点燃敌人时 | 原版敌人效果行为 `on_burned`（每段燃烧的第一次结算） | 25 | — |
| 首次命中敌人时 / 首次用 [近战 / 远程 / 元素 / 工程] 伤害命中敌人时 | 原版敌人效果行为 `on_hurt`（冰块、潜水员的"首次命中"），按命中的伤害缩放属性区分 | 110 / 70 | — |
| 命中生命值高于 [50 / 75 / 90]% / 低于 [25 / 50]% 的敌人时 | 同上，按命中前的生命百分比（小鱼的"对高血敌人增伤"） | 60–200 | 伤害载荷 |

新载荷 **"该敌人受到的伤害提高 X%，持续 N 秒"**（原版冰块的机制）只挂在有目标敌人的扳机上（暴击、点燃、首次命中、命中高 / 低血）。实现为挂在每个敌人身上的本 mod 效果行为节点（原版 `EffectBehaviorService` 框架，与冰块、DLC 的魅惑 / 诅咒相同），通过原版的 `get_bonus_damage` 计入伤害。估值：覆盖率 = 触发次数 × 有效持续（最多 4 秒）/（波长 × 同时受伤的敌人约 8 个），价值 = %伤害权重 × X × 覆盖率。

连锁的例子：击杀 → 爆炸 → "引发爆炸时" → 材料；暴击 → 伤害 → 击杀 → 回血 → "恢复生命时" → ……。保护措施：
- 连锁最多 3 层；爆炸是延迟生成的，参数上携带连锁深度，"引发爆炸时"从该深度继续计数；
- 连锁中的同一条款每秒最多触发 20 次；
- 直接自激的组合不合法：爆炸 → 爆炸、暴击 → 爆炸（爆炸可以暴击）、回血 → 回血、拾取材料 → 材料等。

### 3.5 负面效果的除数与价格模型

Brotato 大部分道具都有加有减：可以卖掉无关或次要的属性来换取重要属性，所以**负面效果的单位价值远低于同属性的正面效果**。对原版纯属性道具拟合 `价格 = 稀有度截距 + Σ 正面权重 × 数值 + Σ 负面权重 × 数值 / D`：

| D | 1 | 1.5 | 2 | 2.5–8 | 不计负面 |
| --- | --- | --- | --- | --- | --- |
| 平均相对误差 | 13.0% | 12.7% | 12.6% | 12.4–12.5% | 12.8% |

数据只能确定"负面远不如正面值钱"，D ≥ 2.5 后误差不再下降，取 **D = 2.5**：-5 远程伤害按 -2 远程伤害计价，生成代价时反过来"想换 X 点预算就要付出 2.5X 的负面数值"。负面触发条款同理。负面机制（下波以 1 HP 开始、敌人速度 +X%……）不再按固定比例估值，而是取来源道具**因它多拿到的正面预算**（正面属性价值 − 预算，至少 3），例如怪异幽灵只值约 10。

**属性权重**：对原版 97 件纯属性道具做岭回归 `价格 = 稀有度截距 + Σ 权重 × 数值`，先验取 ArosRising《Brotato MultiTool》"Value Settings" 的升级等价比（闪避 1 : 最大生命 1 : 暴击 1 : 速度 1 : 近战 1.5 : 再生 1.5 : 工程 2 : 吸血 2 : 远程 3 : 元素 3 : 护甲 3 : %伤害 0.75 : 收获 0.75 : 攻速 0.6 : 幸运 0.4 : 范围 0.15）× 2 材料，岭强度 300。R² = 0.95，价格的中位相对误差 9%。结果（材料 / 点）：

| 最大生命 | 再生 | 吸血 | %伤害 | 近战 | 远程 | 元素 | 攻速 | 暴击 | 工程 | 范围 | 护甲 | 闪避 | 速度 | 幸运 | 收获 | 经验 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2.9 | 3.0 | 4.2 | 1.65 | 2.8 | 5.45 | 4.65 | 1.35 | 1.85 | 3.3 | 0.6 | 6.0 | 2.4 | 2.1 | 0.9 | 0.95 | 0.5 |

**价格**：重组道具不再继承原道具的价格，而是从同稀有度被重组道具的原版价格分布中有放回抽取（按种子与道具 ID 确定；不是均匀分布——T1 集中在 15–25、T2 在 40–50、T3 在 60–80、T4 在 100–110），写到道具资源上，回主菜单时还原。

**预算模型**：同稀有度内预算与价格成正比：

```
预算 = k × 价格，k = 同稀有度原版纯属性道具的净价值中位数 / 价格中位数（T1–T4 约 0.40 / 0.35 / 0.38 / 0.56）
```

原版档内"价值 - 价格"几乎没有斜率（按上面的权重，档内线性回归的 R² 只有 0.07–0.33：T1 的 15 材料与 30 材料道具价值都在 8 左右），所以档内用什么曲线是建模选择，而不是数据能定的事。旧的 `价格 ^ 0.69` 与正比模型对原版数据的解释力相同（R² 都是 0.918，中位相对误差 16.2% / 16.5%）；价格现在由本 mod 生成，用正比关系最直接——同稀有度里贵一倍的道具就强一倍，不再有"便宜道具性价比更高"的隐含折扣。跨稀有度不用同一条直线：T1–T3 的 k 接近（0.35–0.40），T4 明显更高（0.56）。

**估值修正**（参考 MultiTool "Item Efficiency" 的评级与备注，估值越低、同样预算给出的数值越高）：从升级中获得的属性 +X%（藤壶）估值 ×0.6；评级偏低的特殊机制（花园 C ×0.75、眼罩 ×0.8）；计数期望按其假设下调——持有材料 320 → 240、护甲 10 → 8、元素 15 → 12（护垫 D、石皮 C、奇怪的书 C）；经验获取的权重由回归从 0.66 降到 0.5（黑带 D）。

**隐藏价值乘数**：测试 `test_60` 用"真实频率"（击杀 / 材料 110、受击 7、回血 12）重估每档生成道具与原版纯属性道具的强度比 real；real < 1 的档位乘以 1 / real 补齐，real ≥ 1 的保持不变。价格与预算模型改动后重新标定：当前为 T1–T4 = 1 / 1.08 / 1.08 / 1（`catalog.HIDDEN_TIER_MULT`），补齐后 real = 1.04 / 1.00 / 1.00 / 1.05。

另外，击杀 / 拾取材料 / 受击 / 回血的次数略微**高估**（120 / 120 / 10 / 20 次每波，实际约 110 / 110 / 7 / 12），以压低这些高频扳机上的单次数值。

### 4. 扳机的估值：单位价值 × 频率

与东尼算法一样，扳机不单独定价，而是把**载荷单位价值乘以扳机频率**。频率统一用“每波期望次数”（波长按 60 秒估计，大部分波次为 60 秒）：

| 扳机 | 每波次数 | 扳机 | 每波次数 / 在场率 |
| --- | ---: | --- | ---: |
| 击杀 | 120 | 升级 | 1.3 |
| 拾取材料 | 120 | 波开始 / 波结束 | 1 |
| 恢复生命 | 20 | 每 N 秒 | 60 / N |
| 受击 / 拾取消耗品 | 10 / 7 | 静止 / 移动 | 25% / 75% |
| 闪避 | 4 | 低血 / 满血 | 15% / 45% |

不同载荷的“持续方式”不同，所以乘的不是同一个东西：

| 载荷 | 价值 |
| --- | --- |
| 临时属性（本波叠加） | 属性权重 × 数值 × 平均叠层（线性累积 ≈ 次数 / 2；有上限时在上限处饱和；波开始触发 = 整波生效） |
| 状态属性 | 属性权重 × 数值 × 在场率 |
| 限时属性（N 秒） | 属性权重 × 数值 × 次数 × N / 波长 |
| 永久属性（逐次累积） | 属性权重 × 数值 × 次数 × 累积倍率（T1–T4 = 5 / 4.5 / 4 / 3.5，角色 7；由警戒戒指 6.4、机械臂 3.5、魔法叶 3.3、鬼火 2.5、宝宝乌贼 6.1 反推，中位约 3.5） |
| 回血 / 材料 / 经验 | 每波总量 × 0.5 / 0.75 / 0.25（原 1.2 / 1.0 / 0.3：+1 生命再生约每波回复 12 点、权重 2.8，每点仅约 0.25） |
| 伤害 / 爆炸 | 每波总伤害 × 0.022（原 0.055；+1 远程伤害约作用于每波 300+ 次命中，每点伤害约 0.015；爆炸 × 平均命中 2.5） |

这些系数用原版道具校准：例如 **警戒戒指**（每波末 +3% 伤害，92 材料）给出永久累积倍率；**智慧**（每 5 秒 +5% 伤害）给出临时叠层 ≈ 次数 / 2；**赛博球 / 反击** 给出“每点伤害”的价值；**肾上腺素 / 圣杯** 给出回血的价值。

生成条款时（`generator._try_clause`）：先按权重选扳机和载荷，再计算“数值 = 1 个单位”时的价值：

- 预算有余 → 提高数值（每类载荷有合理上限，并受原版单行最大值约束）；
- 预算不足 → **按扳机自身的门控方式降频**：高频扳机用“每 N 次”（每击杀 8 个敌人）、中频扳机用几率、间隔扳机拉长秒数；
- 高频扳机上的永久效果：先按预算定每波上限（2–10，中位约 4），再把触发频率调到上限的约两倍，使多数波次能触发满。

这正是东尼算法里“频率越高，单次载荷越小”的规则在 Brotato 的对应物，而且门控本身就是可读的道具文本（“每击杀 8 个敌人：本波 +1 %攻击速度（每波最多 20 次）”）。

**触发多样性**："本波属性 / 永久属性"两类载荷的基础权重被压低（原版里这两类最多，直接沿用会让道具池充斥"击杀 / 满血 → +属性"）；原版先验改为对数形式，避免压过基础权重；并且像东尼算法的重复反馈一样，**同一道具池中已出现过的 (扳机, 载荷) 组合、扳机、载荷会被降权**。注意状态扳机（静止 / 移动 / 低血 / 满血）只能挂临时属性，所以临时属性载荷的占比天然偏高（约 40%）。

### 5. 其余组件与整件道具的组装

- **属性行**：权重来自价格回归；行数、各属性出现率、负面行出现率都在运行时从原版道具统计（同稀有度的分布），不手写表格。单行数值不超过原版该属性单行最大值的 1.25 倍，超出部分溢出到另一条属性。
- **机制行**：炮台、宠物、受击爆炸、每波额外战利品外星人、燃烧扩散……这些“固定机制”原样搬运，价值 = 来源道具价格 − 稀有度截距 − 其属性行价值；带符号识别代价（“敌人速度 -8%”是好处，“敌人速度 +8%”是代价）。
- **原版按道具 ID 实现的效果**：同样进入机制池，并允许变换数值：
  - 镜子（复制）、金鱼（刷新升档）原版在效果里记录持有者 ID——搬运时改写为新持有者；
  - 原版独特道具的效果多数可以叠加（数值按预算缩放）；叠加会出技术问题的效果，所在的重组道具设为独特：搜刮虫虫（刷怪器每个玩家只记录一只）、覆盖写入型（灯笼的击退光环、幽灵服的闪避上限、干肉条的持续回复、结的锁定武器）、只取一份或开关型（手铐 / 镣铐的上限、链球的最小攻击间隔、海贝壳的每第 X 发投射物、一堆书的构筑物暴击、伐木工人衬衫的一击砍树）；
  - 镜子类复制效果在重组道具上由商店扩展处理，不交给原版：原版按复制份数循环、每份按 ID 找一件持有者整件移除，份数 > 1（按预算缩放或诅咒）时找不到持有者会闪退；现在按份数复制购买的道具，同 ID 的持有者一起生效、各自只失去这一条效果；
  - 珍珠（箱子额外掉落自己）改为"额外掉落这件道具自己"，几率可缩放；藏宝图（随机道具）直接搬运；
  - 沙漏（倒流一波）原版按沙漏 ID 查找持有者，其他道具上由商店扩展处理：进入下一波时倒退波数并移除持有者；
  - 原版这些效果生效后会移除整件持有道具；出现在其他道具上时改为**只移除这一条效果**（放回一件去掉该效果的副本），说明直接写在同一行（"……（生效后此条效果消失）"）；
  - 水晶的"受伤时失去加成"成为触发条款的可选规则（本波属性条款约 20% 带"，受到伤害时清空"，估值按实际受击间隔折算）；
  - 优惠券、刷新价、回收收益、收获增长、存钱罐、鱼钩诅咒锁定、口哨、树上炮台、香肠燃烧、美西螈互换、敌人数量、丑牙减速（上限保持为单次的 4 倍）均可缩放搬运；
  - "敌人数量 −X%"游戏内显示为中性，但实际减少材料与经验，按代价处理；"+诅咒"的实际价值接近 0，不搬运、不计价。
- **保持原样的道具**：道具 ID 本身还有额外含义的望远镜、诱饵、口袋工厂、美西螈、鱼钩，以及金鱼 / 沙漏 / 镜子的用后形态保持原样，但效果可出现在其他道具上；建造者炮台（角色专属）与美西螈（属性互换在商店中按道具 ID 重置）的效果不作为来源。
- **建筑 / 宠物 / 金鱼 / 沙漏 / 镜子**本身也会被重组（重组后去掉"用后变成另一件道具"）；商店对同 ID 的重组道具按本 mod 规则处理。本局玩家角色的初始道具 ID（角色效果里的初始 / 诅咒初始道具，以及开局可选的道具，例如驯兽师的战利品虫和四只可选宠物、法师的蛇和香肠、军火商的危险的兔子）本局默认不重组（"重组初始道具"选项开启时照常重组），商店 / 箱子里的同 ID 道具也是原版：原版背包按 ID 合并显示、存档按 ID 缓存序列化，同 ID 两个版本会显示合并、读档后被覆盖。其他角色的局里这些道具照常重组。
- **核心属性道具**：T1、T2、T3 每档，为 %伤害、近战、远程、元素、工程、攻速、收获、经验获取各保证一件"唯一正面效果就是该属性"的道具（共 24 件，按种子挑选，偏向价格接近该档中位数的道具；被"保留原版道具"滑条保留的道具不参与）。这些道具一律附带一条代价以进一步提高数值，单行上限放宽到普通上限的 1.5 倍，作为构筑的过渡。鬼火这类原版诅咒按 ID 特判属性行的道具不会被选中，也不会生成对应的普通属性行。
- **几率上限**：立即吸取材料、双倍材料、锁定道具被诅咒、箱子额外道具这几种几率，单条效果在生成时不超过 100%（`catalog.PCT_CAPS`）：机制缩放上限取 min(原版 1.5 倍, 100)，"获得"此类效果的单次数量也不超过 100%；价值按截断后的数值折算，多出的预算留给其他行。多条效果叠加、本波获得逐次叠加、诅咒之后超过 100% 与原版一致，不做限制。战利品外星人出现几率是相对值（+100% 只是基础几率 ×2），不在此列。
- **触发频率**：高频扳机（每波 20 次以上：击杀、拾取材料、命中、暴击等）的条款每波至少触发 6 次，避免"每命中 30 次……"这种门槛；预算不足时一半改用几率门控（"击杀敌人时（25% 几率）"，类似幸运币），单次伤害可以低至 25%，优先"频繁的小效果"。每波开始时不生成"本波 +X 属性 / 本波获得"（整波持有，等同于直接写在道具上），只保留永久获得与限时属性。
- **升级所需经验 ±X%**（变异体 / 宝宝 / 技术法师 / 船长）进入"更多角色效果"的池（正面与代价）：按反比例估值，等价获得经验 = 100 / (1 + X%) − 100（−67% 所需经验 = +203% 获得经验，+100% = −50%）；单条正面最多 −60%，代价最多 +200%；多条叠加后运行时总和不低于 −90%。
- **全部角色效果（BETA 选项）**：只加入原版可以直接复用的角色效果——不新增效果、不给原版打补丁，也不需要额外的诅咒处理。
  - 代价（换来的预算，单位材料；min = 道具总预算下限）：一击必死 45（min 35）、进店摧毁所有武器 + 商店至少一把武器 40（min 30）、移动时无法攻击 30（min 25）、无法回血 18（同一道具不再出现回血条款 / 机制）、只能装备 II 级及以下武器 18、无法装备近战 / 远程武器 各 10、无法装备两把相同武器 8、近战与远程武器各最多 3 把（两行）6、只能装备 II 级及以上武器 4、X% 水果有毒 6（按 33% 折算，10–50%）、击杀精英后精英变强 6、无法拥有构筑物 5、无法锁定道具 8。
  - 好处：所有武器计入套装 10、商店至少出售一把武器 2、升级时获得武器栏而不是属性（上限 6 + k，每个武器栏净值约 13）、每个商店可偷 1 件道具（偷窃可能生成精英，每波约 12）、"商店总是出售 [某件一级道具]" + "每有 1 个该道具获得 +N 属性"（渔夫与诱饵，两行捆绑；该道具平均持有约 3.5 件）。
  - 设定值 / 列表型效果（一击必死、武器等级 / 数量上限、摧毁武器、升级换武器栏、商店保底……）原版每个角色只有一份，叠加后撤销会出错：带这些效果的道具设为"独特"。武器等级 / 数量上限、升级换武器栏的诅咒方向不对（原版把上限当负面减小，反而更严），这几行设为中性，诅咒不改。
  - 排除：初始道具 / 武器（只在开局生效）、恶魔的材料转生命 + 用生命购物（诅咒会反向加强转换比例）、建造者的材料转构筑物属性（子效果不走原版诅咒）、渔夫的强化诱饵（只对诱饵生效）、无法装备武器（中途获得时已有武器的处理未定义）、诅咒 / 空文本的内部效果（额外诅咒、偏好词条加权、炮台上限、树木开局）；升级属性 ±X% 已由藤壶进入常规机制池。
- **更多双面效果（选项）**：常规池里只以好处 / 只以代价出现的效果加入对立面。
  - 可缩放机制的反面作为代价：-X% 材料掉落、-X% 敌人材料掉落、-X% 对首领伤害、-X% 回收收益、-X% 波初材料、-X% 构筑物攻速、-X% 战利品外星人几率、-X% 升级属性、+X% 刷新价格、+X% 敌人速度。价值 = 正面每单位价值 × 数值 / 负面除数，数值上限 15–50%（`catalog.DOUBLE_NEG_CAPS`，不会出现 -100% 这种等于禁用的数值）。
  - 负面机制的反面作为好处：-X% 敌人生命 / 伤害（最多 15%），按敌人属性的整局价值估值；每波结束时敌人生命 / 伤害 -1~2%（船长的反面，逐波累积）；下一波敌人属性 -X%（最多 40%）。
  - 角色效果的反面作为代价：-X% [类型] 武器属性、+X% 武器价格、+X% 道具价格；-1 武器栏只在此选项开启时出现（常规池只有 +1）。
  - 触发条款的代价可以是"失去 X 材料"（击杀、受伤、闪避、间隔、消耗品），材料不会低于 0。
- **武器类型加成**（使用 [类型] 武器 +X [属性]）：除原版角色用过的攻速、%伤害、范围、吸血、伤害、暴击伤害外，还会出现暴击率与贯通。原版把类型加成的数值直接加到武器属性上，暴击率会变成 +500%、贯通会被远程武器的通用计算覆盖，由本 mod 的 WeaponService 扩展修正；近战武器没有贯通字段，贯通只给全是远程武器的类型（原版只有枪械）。
- **非线性估值**：拷问（每秒回复 X 生命、不能以其他方式回血）回复太少时等于"无法回血"，价值 = 单位价值 × (X − 3)，X 至少 4。
- **计数期望**："每把不同武器"由 3.5 降到 2.5（同样预算数值更高）。
- **带每波上限的永久效果**：每次触发的期望价值按 0.55 折算（上限常在波次后段才达到），同样预算下每波上限约为原来的 2 倍，上限最大值 10 → 20。
- **稀有度限制**：T4 道具不出现 +收获（与原版一致）。T3 及以上的道具至少有两条效果：只有一条时，把最大的正面属性行拆出一半换成另一条等价的属性行；唯一的效果是触发条款 / 机制时，加一条代价和它换来的一条正面属性（价值不变）。
- **偏好词条的保底**：角色"想要的词条"有 5% 几率只从带该词条的道具中抽，某稀有度一件都没有时原版会退回到不检查角色禁用的备用池。开局时把本局所有玩家角色的偏好词条合成一个集合，去掉八种核心属性（核心属性道具已保证），对剩下的每个词条、T1–T3 每个稀有度，如果重组后没有带该词条的道具，就把该稀有度的一件重组道具（优先选原版就带该词条的，图标一致）重新生成为带该词条的道具，只在本局有效：属性词条生成单属性道具；诅咒词条附加原版的"+1 诅咒"行；其他功能性词条（消耗品、建筑、宠物、爆炸、静止、拾取、探索、敌人数量……）重新生成直到带上该词条，仍不行就围绕一条带该词条的机制生成。敌人数量词条只由敌人数量效果本身给出，不随来源道具继承到其他机制上。
- **功能性词条**：深海 DLC 的 5 件诅咒道具保留原版的"+诅咒"行与 stat_curse 词条（价值约为 0；水手、生物想要这类道具）；敌人数量增减无论作为好处还是代价，都带 more_enemies / less_enemies 词条（大嗓门、老人按它筛选）。这些诅咒道具不会被选为核心属性道具。
- **计数型**："每有 [计数] 获得 [属性]"（原版的石皮、炒饭、社区支持、护垫、幸运币……）在原版里就是同一个通用效果类，计数可以是任意属性（永久 / 含临时）、材料、建筑、存活敌人、燃烧敌人、树、已损失生命%、不同道具数、普通 / 传说道具数。现在计数与目标属性**自由搭配**重新生成，价值 = 目标属性权重 × 数值 × 计数期望 / 每 N。计数期望由原版道具反推：存活敌人约 24、燃烧敌人约 8、护甲约 8、元素约 12、速度约 16、暴击 / 闪避约 25、材料约 240、普通道具约 12、传说道具约 1.5（`catalog.COUNTER_REF`）。不同道具 / 普通道具 / 传说道具 / 存活敌人 / 燃烧敌人 / 树 / 空闲武器栏这几种计数的原版文本不显示"每 N 个"（原版只用 N = 1），生成时 N 固定为 1：单个计数的价值就是这条效果的最小价值，明显超过预算时换别的计数或属性，仍不合适就改用别的词条。
- **属性修改 ±XX%**（来自角色，例如"最大生命值修改提高 33%"）：该属性的所有增减乘以 (1 + XX%)，价值 = 属性权重 × 属性期望总量 × XX%，也可作为代价（"护甲修改降低 10%"，按除数折算）。
- **可缩放机制**：原版里只带一个数值、含义线性的机制（穿透、弹射、双倍材料几率、材料掉落、Boss 伤害、免费刷新、更多树、建筑攻速……）搬运时按预算缩放数值（1 单位 .. 原版 1.5 倍），价值按比例折算。
- **整件道具**：预算 = 档位预算 × 隐藏乘数 × 平均数值 × 浮动。按原版概率加代价（负面属性 / 负面触发 / 负面计数 / 负面属性修改 / 负面机制），代价按除数 D 换成额外正面预算；再按"原版特殊行比例 × 触发效果滑条"加特殊行，类型比例为触发条款 50%、计数型 20%、搬运机制 22%、属性修改 8%，剩余预算分给属性行。

原版全部非纯属性效果（275 种 key × 处理方式组合）的处理方式见 [COVERAGE.md](COVERAGE.md)，由测试自动生成并保证无遗漏。名称 = 主效果形容词 + 原版名称（“复仇土豆”“扎根咖啡”），每种属性 / 扳机 / 特殊行类型各有 2–4 个候选形容词，共约 100 个。

价值审计（5 个种子 × 204 件道具，测试 `test_12`）：生成价值 / 该道具预算的 p10 = 0.93、中位数 = 1.00、p90 = 1.08。

- **角色效果（可选）**：假设各角色总价值相近。只由可估值行组成的角色给出"角色总价值"（中位数，至少 60），其余角色每条可搬运机制 = (角色总价值 − 可估值部分) / 机制数，并限制在 30–80 之间（角色机制常是整局核心，保守估值，只会出现在预算较高的道具上）。武器限制、初始装备、商店规则等身份 / 结构性效果不搬运。

### 5.5 道具池结构：攻击 / 生存 / 运营

把属性分为三类——攻击（各种伤害、%伤害、攻速、暴击、工程、范围、爆炸、击退）、生存（最大生命、再生、吸血、闪避、护甲、消耗品回复、速度）、运营（幸运、收获、经验、拾取范围）；触发载荷同样归类（回血 = 生存，材料 / 经验 = 运营，伤害 / 爆炸 = 攻击）。原版道具按"正面主类 × 负面主类（或无负面）"分为 12 类：

| 正面 \ 负面 | 攻击 | 生存 | 运营 | 无 |
| --- | --- | --- | --- | --- |
| 攻击 | 19% | 12% | 1% | 15% |
| 生存 | 12% | 10% | 5% | 13% |
| 运营 | 5% | 4% | 1% | 4% |

原版的设计倾向：约一半道具以攻击为主；**最常见的是同类内交换**（+近战 −远程、+攻速 −%伤害、+生命 −再生）；运营几乎从不作为代价，以运营为代价的道具也没有明确规律——所以负面类为运营时不再约束类别，负面属性自由生成。生成时：

1. 按原版同稀有度的 12 类分布抽取道具类型，先定主属性；
2. 其余正面属性偏向同类，并按原版**共现**加权（近战常与击退、远程常与范围同时出现）；击退、范围、拾取范围是**次要属性**：作为非核心属性行时只拿到通常份额的 50% / 65% / 50%，余下预算转给后续属性行；
3. 负面属性从负面类中抽，并按原版"正面属性 → 负面属性"的交换关系加权；
4. 触发条款的载荷偏向本道具的正面类。

生成池与原版的类型分布 L1 距离约 0.15（测试 `test_70`）。

**词条**：原版商店每次抽道具有 5%（部分效果下 10%）概率只从带角色"想要词条"的道具中抽。生成道具的词条 = 正面属性 key + 原版风格的非属性词条（消耗品回复 → consumable，爆炸 → explosive，静止扳机 → stand_still，材料载荷 → economy，搬运机制带上来源道具的 structure / pet 等词条），保证角色偏好依然有效。

**禁用**：原版角色的"禁用道具组"和"禁用道具"都按道具 ID 写死，重组后会错位。现在按语义重建：道具组 = 主属性满足该组属性的生成道具；角色禁用 = 与被禁用原版道具的**禁用原因**相同的生成道具。原因优先取规则性的（回血、下波低血开局、满血条件、持续掉血），否则取主属性——例如魔像禁用肾上腺素、额外的胃、怪异幽灵的原因都是"无法回血"，而负伤者禁用的是所有生存类道具。角色想要的词条优先于禁用原因：例如多面手原版禁用专精（+近战 −远程），但它想要近战，因此不会禁掉所有以近战为主的道具；幽灵想要闪避，同理。

### 6. 为什么直接改写原版资源

生成结果直接写回 `ItemService.items` 里的原版 `ItemData`（以及选中角色的 `CharacterData`、武器的 `WeaponData`），保留 `my_id`、图标、稀有度、价格：

- 商店、箱子、传奇箱子、角色偏好标签、诅咒（深海魔怪 DLC 的 `curse_item` 对通用条款同样有效）都自动沿用，不需要逐一拦截；
- 存档按 `my_id` 找道具再合并已保存的效果，天然兼容；
- 开局时已持有的角色 / 初始道具 / 初始武器，会先撤销旧效果再应用新效果（测试 `test_22` 逐项核对属性）；
- 回到主菜单时还原所有备份。

存档细节：本局种子与设置作为 `aa_state` 写入 `RunData.get_state()`；读档时 `resume_from_state` 按种子重建。由于游戏启动时存档可能在本 mod 注册效果脚本之前就被反序列化（ModLoader 在 ItemService 之前加载），读档后会修复持有道具：未诅咒的直接换回模板，诅咒的补回触发条款并按诅咒系数增强。

### 6.5 与其他 mod 共处、诅咒

- **其他 mod 的道具 / 角色 / 武器**：只重组资源来自原版目录（`res://items/`、`res://dlcs/`、`res://weapons/`）的内容；其他 mod 加入的内容（来自 `mods-unpacked` 或由脚本创建）不重组、不参与先验统计、不作为机制来源，照常留在道具池里（测试 `test_94` 用一件伪 mod 道具验证）。
- **诅咒（深海魔怪）**：原版诅咒按效果类型逐条处理，正面加强、负面减弱。生成内容全部复用原版效果类或以 `value` 为主数值（触发条款的数量 / 数值、计数型、属性修改、下一波、武器类型加成……），不写复合效果（成对的正负条款是两条独立效果），敌人属性条款显式标为负面符号，因此完全交给原版诅咒系统处理，无需额外钩子。测试 `test_95` 把两套生成道具池（430 件）逐件诅咒并检查方向、文本与运行时。
  - 已知的原版行为：数值为 1 的行诅咒后会取整到 2（原版同样如此）；镜子类"复制"效果出现在其他道具上时，诅咒增加的是复制份数，而不是原版镜子的"道具价格"代价。

### 7. 重组角色与武器的取舍

- **角色**：角色的“身份”大多在非属性行里（初始武器、武器限制、`no_heal` 之类的规则、特殊机制），这些保留。其余可估值的行按同等价值重新组装，并偏向角色的偏好词条（`wanted_tags`）：
  - 正面属性行（≤ 20）→ 属性行 40% / 触发条款 35% / 计数型 13% / 属性修改 12%；正面属性修改、正面计数有 50% 同样换成这四类之一（偏好属性上的修改 / 计数是角色核心，例如法师 +25% 元素，保留）；
  - 偏好属性作为正面的权重 ×4（作为代价 ×0.1），绑定了偏好词条的扳机 / 载荷 / 计数（例如偏好"静止"→ 静止时扳机，偏好"构筑物"→ 每个建筑计数）同样 ×4；实测新正面行命中偏好词条的比例 0.37（均匀随机约 0.07）；
  - 普通负面属性行换到非偏好属性、数值强度不变；部分降低的属性修改（-25% .. -80%）换到非偏好属性、百分比不变；
  - **"禁用"行**：-100% 属性修改（法师的近战 / 远程）、数值远超属性期望总量的负面行（吸血鬼 -100 生命再生 / 消耗品回复、速度型"静止时 -100 护甲"）只是"让该属性归零"，-100 本身没有意义。这些行保留为身份行，估值时数值不超过该属性的期望总量（`catalog.COUNTER_REF` / 参考值 ×1.2），不再按 -100 × 权重线性计价（这也修正了"角色效果进入道具池"时这类角色的机制估值）；
  - 原版触发行（魔像的“低血时”、受虐狂的“受击时”、学徒的“升级时”）只重组一半：随机保留扳机换载荷，或保留载荷换扳机，让角色重组后仍然像自己；无法回血的角色不会拿到回血相关条款。
  - 审计（全部角色 × 8 个种子，测试 `test_115`）：重组后可估值部分的价值 / 原价值 p10 = 0.70、中位数 = 0.99、p90 = 1.17。
- **武器（实验）**：武器的特效（燃烧、近战爆炸、击中闪电、暴击拿材料、召唤炮台……）大多作为 `NullEffect` 从武器数据里按类读取，可以在同类型武器家族之间按等级整套互换；“同名武器叠加”这类引用自身 ID 的效果会重定向到接收方。武器的基础数值、攻击方式、套装不变，所以数值平衡只是近似，默认关闭。
