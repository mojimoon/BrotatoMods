# 更新日志

## 1.6.4（2026-10-06）

### 平衡性调整
- 深度重组武器的升级改为"先定最高一级、再插值"：
  - 由最低一级估出最高一级的价格；效果保持在总强度中的占比（最多放大 3 倍，且每级必有提升），伤害、加成、高暴击武器的暴击一起放大到对应强度。
  - 中间各级按原版的逐级比例插值，升级更平滑；攻速每级略快，远程武器每级射程 +50、长柄近战武器每级 +25，吸血每级 +5%，弹跳每级 +1。
- 最低一级不再偏向"最优解"：武器构成（攻速、射程 / 贯穿 / 弹跳 / 吸血、效果条数）先定，再随机数值，取第一组强度合适且面板自然的。效果、贯穿等的出现比例与纯随机一致。
- 传奇武器的攻速按同稀有度的价格挑选，不再总是挑到最慢最重的类型（不会再出现单发上千伤害的传奇武器）。
- 慢速武器的加成系数也设上限。

## 1.6.2（2026-10-06）

### 平衡性调整
- 深度重组武器的生成流程重写：
  - 最低一级：先定价格和攻速，再定是否为高暴击武器，然后随机多种（基础伤害、加成、暴击、射程 / 贯穿 / 弹跳 / 吸血、效果）组合，取价值不超过价格对应强度中最好的一组。
  - 更高一级：在低一级的基础上，攻速、加成、贯穿 / 弹跳 / 吸血 / 射程等各有一定几率提升（否则不变），高暴击武器的暴击必定提升，效果必定提升，基础伤害补足其余；价格按实际强度重新计算。
- 武器加成系数设下限（约为终局属性 15 点时的加成，且不高于原版该属性的最低系数）：例如近战伤害 25%、远程伤害 40%、元素伤害 25%、最大生命 15%、收获 5%。
- 移除各稀有度武器强度的 100% / 95% / 90% / 85% 折扣。

## 1.4.7（2026-10-05）

本次更新带来**重组武器**，并把设置拆成道具 / 武器 / 角色三页。

### 新内容

**设置页**
- 设置拆成三个页签：**重组道具 / 重组武器 / 重组角色**，每个页签右侧是本页的总开关（武器、角色默认关闭）。种子与启用开关移到页首。
- 预览改为点击时只生成当前页（道具或武器），每行显示 4 张卡片。
- 在选择武器界面就会生成本局内容，界面上直接显示重组后的武器；在这里改了设置会重新生成，返回角色选择时撤销。

**重组道具页的新选项**
- **保留原名**（默认关，取代原来的"重组名称"）。没有具体特征时的保底名称从 4 个增加到 10 个，"古怪的"不再频繁出现。
- **强制重组 (BETA)**：望远镜、诱饵、口袋工厂、美西螈、金鱼、鱼钩也参与重组。
- **混沌**：被重组的道具之间随机交换稀有度。
- **究极混沌**：在混沌的基础上再随机交换图标（与混沌互斥）。

**重组武器**
- **仅重组效果**：武器保留原有属性，换用随机武器家族的效果（可跨近战 / 远程），按效果价值调整伤害。
- **深度重组**（默认）：伤害、属性加成、冷却、暴击、生命窃取、投射物、贯穿、弹跳、换弹、特殊效果和武器类别全部重新生成，按原版武器的分布与等效 DPS 平衡；近战 / 远程不变。
  - 大部分武器以本类型的伤害为主加成，少数以元素或其他属性为主；附加加成数值较小，逐级增长幅度参考原版。
  - 慢速武器较少出现，但可以有更高的加成。
  - 基础伤害有下限（T1–T4：3 / 5 / 7 / 10），不会出现 1 点伤害的武器。
  - 武器类别按武器的特性选取（爆炸 → 爆炸类、吸血 → 医疗类、诅咒加成 → 海军类……），每个类别都保证有足够的武器。
  - 传奇武器按原版的强弱程度重新估值（链枪仍是最强的远程武器）；其余 T4 武器略微削弱。
- **引入道具效果**（默认开）：武器可能额外获得一条道具的属性或触发效果，常与武器的加成属性相关。
- **额外效果**滑条（默认 125%）：控制有额外效果的武器数量与条数，100% 接近原版。
- **保留原名**（默认关）：武器名 = 特征形容词 + 原名称。
- **补全低级武器**：原本没有低级版本的武器（剑、火箭筒、王者之剑……）补齐到 T1，可以在商店购买、合成，读档正常。
- **任意初始武器**（默认开）：开局可以选择任意已解锁武器，稀有度与原角色的初始武器一致。
- 独立的平均数值、浮动范围滑条。

### 平衡性调整
- 道具"浮动范围"默认值 125% → 100%，"触发效果"默认值 150% → 125%。
- 爆炸效果搬到其他武器上时按武器类型改写：近战为"命中时 X% 几率爆炸"，远程为"投射物爆炸"。
- 击退不再占用武器的价值预算，并参考原版数值（近战最多 15、远程最多 8）。

### 问题修复
- 未启用 DLC 时，重组武器不会再以"诅咒"作为加成属性（原版计算伤害时会报错）。

## 1.2.0（2026-10-02）

本次更新带来大量新的触发条件与效果，进一步拆解原版的触发型道具，并全面重写了效果文本。

### 新内容

**新的触发条件**
- 击杀被诅咒的敌人时（原版黑旗）。带有此条件的道具同时附带 +5 诅咒，让被诅咒的敌人出现。
- 砍倒树木时（原版口袋工厂）。
- 每次获得一个提升 [属性] 的道具时（原版雪球），效果为永久提升同一属性。
- 用 [类型] 伤害击杀敌人时（以致命一击的伤害类型为准，燃烧致死算作元素伤害）。

**新的效果**
- 按该敌人当前生命值的 X% 造成伤害（头目和精英为 X/10%；原版巨型带、希腊火）。
- 将 X 点属性点随机分配到主要属性上（原版糖果袋）。
- 点燃该敌人（原版害怕的香肠）。
- 降低该敌人 X% 速度，最多降低 4X%（原版丑牙）。
- 掉落 X 个水果，可与"捡起消耗品时"的效果配合。

**更灵活的触发条件**
- 以下触发条件新增"每 N 次"写法：受到伤害、闪避、捡起消耗品、砍倒树木、刷新商店、购买道具。
- 绝大多数触发条件现在都可以是单次、概率或每 N 次三种形式之一。
- 作用于敌人本身的效果（易伤、按生命值伤害、点燃、减速）只会以单次或概率形式出现。
- 限定伤害类型的触发条件按 近战 : 远程 : 元素 : 工程 = 2 : 2 : 2 : 1 的比例出现。伤害与爆炸效果的伤害来源属性落在这四类时，也按同一比例分配。

**拆解更多原版道具**
- 冰块、金属探测器、巨型带、希腊火、糖果袋、黑旗、害怕的香肠、丑牙、雪球的效果被拆成"触发条件 + 效果"，作为重组素材自由搭配，不再整条照搬。

### 平衡性调整
- **独特道具**：带有以下原版独特效果的重组道具设为独特，避免多件叠加出现问题：
  - 击退光环、闪避上限、消耗品持续治疗、锁定当前武器
  - 生命上限、速度上限、武器最低冷却
  - 每 X 发投射物修改、构筑物可以暴击、一击砍倒树木、搜刮虫虫
- **易伤叠加**：规则与原版一致，同一来源不叠层（取较大值并刷新时间），不同来源相加。
- **冰块与潜水员**：重组道具上的冰块效果按持有者计算来源；潜水员的易伤效果属于角色身份，不再转移到道具上。
- **"消耗品在 X 秒内持续治疗"**：文字虽为绿色，实际是代价（干肉条正是靠它换来高额属性），现在按负面效果估值，并带有消耗品词条。
- **触发频率估计**：
  - "击杀被诅咒的敌人时"按每波约 25 次估计。
  - "首次命中敌人时"与"敌人首次被 [类型] 伤害命中时"均按每波约 110 次估计（一局通常只用一种伤害类型）。
- **果篮**：恢复为整条原样出现，不再拆成"击杀时掉落水果"（敌人本身就有概率掉落各不相同的消耗品）。
- **掉落水果**：这个效果不会出现在波次开始或结束时，波次结束清场后也不再掉落。

### 文本与本地化
- 所有触发条件和效果的文本，按原版同类效果的措辞与语序重写，覆盖全部 13 种语言。
  - 简体中文等语言为"触发在前、效果在后"，英语等语言为"效果在前、触发在后"。
  - 短条件直接接效果（"移动时 +5% 速度"），长条件用逗号分隔（"命中生命值高于 75% 的敌人时，有 65% 概率……，持续 4 秒"）。
- 每波上限改为显示可获得的总量（"每波最大值：+8"），与原版一致。
- 设置页数值选项的说明更新为更直观的表述（全语言）。
- 道具词条更准确：
  - 武器伤害随属性提升、武器类型加成等效果会带上对应属性的词条。
  - 不再出现原版没有的词条。

### 问题修复
- 修复"每暴击击杀 N 个敌人"类效果不生效的问题。
- 修复临时降低最大生命值（如"移动时 -2 最大生命值"）在有生命再生时导致满血回血、超出上限的问题。现在当前生命值 = min(当前生命值, 降低后的最大生命值)。
- 修复持有"复制购买的道具"（镜子类）效果的重组道具时，购买下一件道具会闪退的问题。
- 修复在商店中触发"随机分配属性点"效果不生效的问题。
- 修复部分环境下游戏无法启动的问题。
- 移除"发射投射物"效果。婴儿胡子与外星之眼恢复为整条原样出现。
